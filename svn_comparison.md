# Сравнение Git и SVN

## 1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
В Git ветка — это просто указатель на коммит (файл размером 41 байт). Переключение между ветками происходит мгновенно. 
В SVN ветка — это физическая копия директории на сервере. Создание ветки требует копирования всех файлов, что медленно и занимает место.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет, нельзя. SVN — централизованная система. Коммит отправляется напрямую на центральный сервер. Без сети commit невозможен. Можно только сохранить локальные изменения в рабочей копии, но не зафиксировать их в истории.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
- В legacy-проектах (банки, госсектор), где уже настроена инфраструктура SVN и нет смысла тратить ресурсы на миграцию.
- Если команда состоит из новичков, которым сложно освоить распределенную модель Git.
- Если нужен жесткий централизованный контроль доступа к каждому файлу (в SVN это реализовано проще).
